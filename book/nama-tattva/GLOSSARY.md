# Glossary of Sanskrit Terms

*Terms are given in IAST. Definitions are concise and keyed to how the term is used in this book;
chapter references point to where the term is central.*

| Term | Meaning |
|---|---|
| **abhidheya** | The *process* — the practice (chanting, hearing) that connects the soul to Kṛṣṇa; the middle of the sambandha–abhidheya–prayojana arc. |
| **abhinnatva** | Non-difference; the principle that the holy **name** and the **named** (Kṛṣṇa) are one and the same. *(Ch 1)* |
| **ācārya** | A spiritual teacher who instructs by living example and stands in disciplic succession. |
| **agha-kṣaya** | The destruction of sin. *(Ch 19)* |
| **ahaṅkāra** | False ego — the misidentification "I am the doer / enjoyer," which links the soul to matter. *(Ch 4)* |
| **anartha** | An "unwanted thing" lodged in the heart — a residue of the enemies that obstructs the taste for the name. *(Ch 5)* |
| **anartha-nivṛtti** | The clearing away of anarthas, said to proceed in four degrees. *(Ch 18)* |
| **aparādha** | Offense; **nāma-aparādha** = the ten offenses to the holy name. *(Ch 7)* |
| **āśraya / āhāra / nidrā / saṅga** | shelter / food / sleep / association — lifestyle factors that shape consciousness. *(Ch 15)* |
| **brāhma-muhūrta** | The auspicious ~1.5-hour period before sunrise, when the mode of goodness predominates — the recommended time for chanting. *(Ch 15)* |
| **bhakti** | Loving devotional service to Kṛṣṇa. |
| **bhakti-latā** | The "creeper of devotion," grown through nine stages from faith to prema. *(Ch 21)* |
| **damaḥ** | Self-control; subduing the senses and the inner enemies. *(Ch 14)* |
| **guṇas** | The three modes of material nature — *sattva* (goodness), *rajas* (passion), *tamas* (ignorance). *(Ch 4, 15)* |
| **guṇa-saṅga** | Association with / contact with the modes — the mechanism by which the soul is conditioned. *(Ch 4)* |
| **japa** | Soft, individual chanting of the mahā-mantra, usually counted on beads. |
| **jīva** | The individual living entity — Kṛṣṇa's eternal, minute part. |
| **jitendriya** | One who has conquered the senses. *(Ch 17)* |
| **kīrtana / saṅkīrtana** | Congregational chanting/singing of the holy names. |
| **kṣamā** | Forgiveness. *(Ch 20)* |
| **Kṛṣṇa-prema** | Pure love of Kṛṣṇa — the goal (prayojana) of all practice. *(Ch 21)* |
| **laulyam** | Intense spiritual greed or longing — the sole "price" of Kṛṣṇa-prema. *(Ch 21)* |
| **mada** | Pride, intoxication with one's position — one of the six enemies. |
| **mahā-mantra** | The "great mantra": *Hare Kṛṣṇa Hare Kṛṣṇa, Kṛṣṇa Kṛṣṇa Hare Hare / Hare Rāma Hare Rāma, Rāma Rāma Hare Hare.* |
| **māna-dāna** | Offering respect to others (from Śikṣāṣṭaka 3, *amāninā mānadena*). *(Ch 12)* |
| **mātsarya** | Envy — the subtlest of the six enemies. |
| **māyā** | The Lord's illusory material energy. |
| **nāma** | The holy name. **nāma-nāminoḥ** = "of the name and the named." |
| **nāmābhāsa** | The "shadow" of the name — a clearing but still-impure stage of chanting, between offensive and pure. *(Ch 8)* |
| **nāma-aparādha** | Offense to the holy name; the ten offenses. *(Ch 7)* |
| **nāma-prabhāva** | The potency / power of the holy name. *(Ch 1)* |
| **nāma-roga-nirṇaya** | "Diagnosis of the disease (that blocks) the name" — the book's self-diagnostic chapter. *(Ch 9)* |
| **nāma-ruci** | Taste for the holy name. *(Ch 15)* |
| **nāma-uddhāra** | Deliverance / uplift by the holy name. *(Ch 2)* |
| **nāma-vighna** | Obstacle to (the fruition of) the name. *(Ch 3)* |
| **niraparādha** | Offenseless (chanting). *(Ch 13)* |
| **pāpa** | Sin. *(Ch 6)* |
| **paramparā** | Disciplic succession — the chain through which teachings are transmitted intact. |
| **pramāda** | Inattention / heedlessness — the chief daily enemy of japa. |
| **prayojana** | The ultimate goal — Kṛṣṇa-prema. |
| **ṣaḍ-ripu** | The "six enemies": *kāma* (lust), *krodha* (anger), *lobha* (greed), *moha* (illusion), *mada* (pride), *mātsarya* (envy). *(Ch 4)* |
| **sādhana** | Regulated daily spiritual practice. |
| **sādhu-saṅga** | Association with saintly devotees. |
| **sahiṣṇutā** | Tolerance / forbearance (from Śikṣāṣṭaka 3, *taror api sahiṣṇunā*). *(Ch 11)* |
| **sambandha** | One's eternal relationship with Kṛṣṇa — the foundational knowledge. |
| **samādhāya** | "Having concentrated / settled" — fixing the mind in the heart (SB 8.3.1). *(Ch 14)* |
| **śāstra** | Revealed scripture. |
| **śraddhā** | Faith — the seed and starting point of devotional life. |
| **śuddha-nāma** | The pure name — the third and highest stage of chanting. *(Ch 8)* |
| **taṭasthā** | "Marginal" — the constitutional position of the jīva, able to face either energy. *(Ch 4)* |
| **tṛṇād api sunīcena** | "Lower than the straw in the street" — the humility of Śikṣāṣṭaka 3. *(Ch 10)* |
| **vinaya** | Humility. *(Ch 10)* |
| **Vaiṣṇava-aparādha** | Offense to a devotee — the gravest of the ten offenses. *(Ch 7)* |
