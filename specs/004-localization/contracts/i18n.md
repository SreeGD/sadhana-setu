# Contract: i18n + Transliteration

## `sadhana_setu/i18n.py`

```python
LOCALES = ("en", "te", "kn", "ta")

def get_locale() -> str: ...           # st.session_state["locale"] or settings file; default "en"
def set_locale(code: str) -> None: ... # validate ∈ LOCALES; persist

def t(key: str, **fmt) -> str:
    """UI string for the current locale from data/i18n/ui/<locale>.yaml, English fallback per key
    (FR-002). Never returns blank. `fmt` for str.format placeholders."""

def localize_content(library: str, item_id, field: str, english: str, *, locale=None) -> str:
    """The REVIEWED translation of one content field from
    data/i18n/content/<locale>/<library>.yaml, or `english` if missing/unreviewed (FR-003/004,
    Constitution V)."""
```

Guarantees:
- English fallback for any missing UI key or content item (no blanks; SC-001).
- Only entries with `reviewed: true` are returned; unreviewed ⇒ English (SC-002).
- Catalogs loaded once and cached.

## `sadhana_setu/translit.py`

```python
def to_script(text: str, locale: str, *, src: str = "iast") -> str:
    """Transliterate `text` (IAST/Devanāgarī) into the locale's script (te/kn/ta), preserving the
    exact Sanskrit sounds (FR-010). Returns `text` unchanged for locale 'en' or on any
    transliteration failure (IAST fallback)."""
```

Fidelity (tested): `to_script("Hare Kṛṣṇa", "te")` → `హరే కృష్ణ`; the mahā-mantra and a sample
verse round-trip correctly for te/kn/ta (Constitution I).

## Usage pattern (views/content)

```python
st.header(i18n.t("view.nama_tattva"))                       # UI string
text = i18n.localize_content("affirmations", a.id, "text", a.text)   # content (reviewed) or English
verse = i18n.maybe_transliterate(v.iast)                    # vernacular script in te/kn/ta locale
```
